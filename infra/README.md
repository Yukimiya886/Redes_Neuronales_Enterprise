# Infraestructura

Centraliza la configuración de entorno, despliegue y soporte operativo.

## Incluye

- contenedores y servicios
- migraciones de base de datos
- monitoreo
- variables de entorno
- configuración de ejecución

## Tecnologías sugeridas

- Docker
- Docker Compose
- PostgreSQL
- Grafana
- Prometheus
