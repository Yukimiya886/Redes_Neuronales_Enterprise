# Frontend web

Aquí vive la interfaz de la aplicación.

## Responsabilidades

- Dashboard principal
- Gestión de proyectos
- Diseñador de arquitecturas
- Visualización de métricas
- Autenticación y roles
- Reportes y auditoría

## Tecnologías sugeridas

- React
- TypeScript
- Vite
- Tailwind o CSS Modules
- React Query
- Recharts o charts similares
