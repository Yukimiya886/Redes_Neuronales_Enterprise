# Redes_Neuronales_Enterprise

Proyecto base para una plataforma de gestión, entrenamiento y evaluación de redes neuronales artificiales.

## Estructura principal

- `apps/web`: interfaz del usuario
- `services/api`: backend del sistema
- `workers`: entrenamiento y tareas asíncronas
- `infra`: entorno, despliegue y configuración
- `docs`: documentación técnica y operativa
- `shared`: contratos y tipos compartidos

## Objetivo

Organizar el proyecto para desarrollar una solución moderna con React, FastAPI, TensorFlow/Keras y PostgreSQL.
