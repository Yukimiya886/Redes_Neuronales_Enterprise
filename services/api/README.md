# API del sistema

Backend principal del proyecto.

## Responsabilidades

- autenticación y autorización
- gestión de proyectos
- creación de arquitecturas
- validación de datasets
- ejecución de trabajos de entrenamiento
- consulta de métricas y modelos
- auditoría de acciones

## Stack sugerido

- Python
- FastAPI
- SQLAlchemy
- PostgreSQL
- Pydantic
- Celery o workers propios

## Módulos base

- endpoints
- modelos
- schemas
- repositorios
- servicios
- utilidades
- core
